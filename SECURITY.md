# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in Strong Notes, please report it privately
rather than opening a public issue.

- **Preferred:** use GitHub's [private vulnerability reporting](https://github.com/DowLucas/strong-notes/security/advisories/new).
- **Alternatively:** email **lucas.dow@fidify.se** with a description, steps to
  reproduce, and the potential impact.

Please give us a reasonable window to investigate and release a fix before any public
disclosure. We'll acknowledge your report as quickly as we can and keep you updated on
progress.

## Supported versions

Strong Notes is under active development and does not yet publish tagged releases.
Security fixes land on `main`.
